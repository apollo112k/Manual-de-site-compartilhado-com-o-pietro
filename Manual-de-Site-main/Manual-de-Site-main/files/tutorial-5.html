<mais css/>

Vamos aprofundar um pouco mais no CSS e praticar com dois exercícios: um para escolher as cores de um código pronto, e outro para completar as lacunas que faltam.

conceito 1

Explicação do CSS: mais conceitos

Além de estilizar tags diretamente (como p ou h1), dá para escolher exatamente qual elemento estilizar usando uma classe: no HTML você escreve class="cartao", e no CSS você usa um ponto na frente — .cartao — para atingir só aquele elemento, sem afetar os outros da mesma tag.

conceito 2

Exercício: escolha as cores

O HTML abaixo já está pronto — você só precisa preencher os valores de cor no CSS. Troque os textos "?" por cores como "tomato", "#1F8F63" ou "royalblue" e veja o resultado mudar.

exercicio-cores.css — complete as cores
<!-- html já pronto --> <div class="aviso"> <p>Tudo certo por aqui!</p> </div> /* css: preencha as cores */ .aviso { background-color: "?"; color: "?"; }
conceito 3

Exercício: complete as lacunas

Agora o desafio é diferente: faltam as propriedades, não os valores. Olhe o resultado que o código deveria gerar e descubra qual propriedade de CSS falta em cada linha.

exercicio-lacunas.css — complete as propriedades
.botao { ___: #1F8F63; /* cor de fundo */ ___: #fff; /* cor do texto */ ___: 8px; /* cantos arredondados */ ___: 10px 18px; /* espaço interno */ }
Curiosidade: classes podem ser reutilizadas em quantos elementos você quiser — se dez tags diferentes tiverem class="cartao", todas recebem o mesmo estilo de uma vez só.
