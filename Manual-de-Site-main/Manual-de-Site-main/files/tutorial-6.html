<fechando o css/>

Último tutorial de CSS! Vamos ver um exemplo completo de código, praticar com um exercício usando um HTML já pronto e fechar tudo o que foi aprendido até aqui.

conceito 1

Um exemplo de código CSS

Este exemplo junta várias propriedades que você já viu — cor, fundo, espaçamento e cantos arredondados — em uma única regra, para mostrar como elas trabalham juntas.

card.css
resultado
.card { background-color: #E7FAF1; color: #1F2421; padding: 18px 22px; border-radius: 10px; font-size: 15px; }
conceito 2

Exercício: CSS com HTML pronto

O HTML de um pequeno perfil já está pronto abaixo. Escreva o CSS do zero usando o que você aprendeu — cor de fundo, cor do texto, espaçamento e cantos arredondados.

perfil.html — pronto
<div class="perfil"> <h2>Seu nome</h2> <p>Uma frase sobre você</p> </div> /* escreva o css aqui: .perfil { ... } */
conceito 3

Finalização do conteúdo de CSS

Recapitulando: CSS é feito de seletores e declarações, pode mirar em tags ou em classes, e tem propriedades para cor, fundo, tamanho de texto, espaçamento e cantos. Com isso você já consegue estilizar qualquer página HTML. No próximo tutorial começa uma nova etapa: dar vida à página com JavaScript.

Curiosidade: existem milhares de propriedades de CSS, mas com menos de 15 delas — as que você viu nesses tutoriais — já dá para estilizar a maioria dos sites do dia a dia.
