Último tutorial da trilha! Vamos aprofundar um pouco mais o JavaScript e fechar com dois exercícios — um para completar lacunas, outro para você criar algo sozinho.

conceito 1

Aprofundar mais em JavaScript

Além de onclick direto no HTML, dá para "escutar" eventos pelo próprio JavaScript com addEventListener, e usar if para tomar decisões — por exemplo, mostrar uma mensagem diferente dependendo do que a pessoa fizer.

conceito 2

Exercício: complete as lacunas

O código abaixo deveria trocar a cor de fundo da página quando o botão for clicado, mas faltam algumas partes. Descubra o que preencher em cada lacuna.

exercicio-lacunas.html — complete o código
<button onclick="___()">Mudar cor</button> <script> function ___() { document.body.style.___ = "lightyellow"; } </script>
conceito 3

Exercício final: crie você mesmo

Desafio: faça um código JavaScript que, quando o botão do meio for clicado, abra uma "interface" nova — pode ser uma caixa com uma mensagem, uma janela simples ou uma seção que aparece na tela. Use o que aprendeu sobre onclick e sobre trocar o conteúdo ou o estilo de um elemento com JavaScript. Não existe uma única resposta certa — o objetivo é praticar juntando tudo o que você viu na trilha.

Curiosidade: HTML, CSS e JavaScript são as três tecnologias que rodam por trás de praticamente todo site que você visita — inclusive este aqui.
