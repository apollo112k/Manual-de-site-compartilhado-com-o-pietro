parte do tutorial 4

<css/>

O HTML organiza o conteúdo, mas quem dá cor, espaçamento e aparência é o CSS. Neste tutorial você vai entender como ele funciona e ver o mesmo site antes e depois de receber estilo.

conceito 1

Explicação do CSS

Uma regra de CSS tem duas partes: o seletor, que diz qual tag vai ser estilizada, e as declarações, entre chaves, que dizem o que mudar. Cada declaração é uma propriedade seguida de dois-pontos e um valor, terminando em ponto e vírgula.

estilo.css
/* seletor */ p { color: #1F8F63; /* propriedade: valor */ font-size: 18px; }
conceito 2

Tags que você pode estilizar e o que dá pra mudar

Praticamente toda tag pode ser estilizada. Algumas propriedades comuns: color (cor do texto), background-color (cor de fundo), font-size (tamanho do texto), margin (espaço fora do elemento), padding (espaço dentro do elemento) e border-radius (cantos arredondados).
