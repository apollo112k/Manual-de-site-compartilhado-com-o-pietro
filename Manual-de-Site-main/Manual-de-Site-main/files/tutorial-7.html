<javascript/>

HTML dá a estrutura e CSS dá o estilo — mas quem faz a página reagir a cliques, digitação e outras ações é o JavaScript. Vamos começar pelo básico.

conceito 1

O básico de JavaScript

JavaScript usa variáveis para guardar informação (let nome = "Ana") e funções para agrupar ações que podem ser executadas quando algo acontece — como um clique em um botão. Diferente do HTML e do CSS, JavaScript é uma linguagem de programação de verdade: ela toma decisões e executa passo a passo.

conceito 2

Exemplo básico de JavaScript

No exemplo abaixo, um botão tem um evento onclick: quando clicado, ele chama uma função que troca o texto da tela. Clique no botão do resultado para ver funcionando.

saudacao.html
resultado (clique no botão)
<p id="texto">Olá!</p> <button onclick="mudar()"> Clique aqui </button> <script> function mudar() { document.getElementById("texto") .innerText = "Você clicou!"; } </script>
conceito 3

Explicação do que cada coisa faz no código

onclick="mudar()" diz ao botão qual função chamar quando for clicado. Dentro da função, document.getElementById("texto") procura na página o elemento com id="texto", e .innerText = "..." troca o conteúdo dele pelo novo texto.

Curiosidade: o JavaScript roda direto no navegador de quem está vendo a página — sem precisar instalar nada nem enviar informação para um servidor.
