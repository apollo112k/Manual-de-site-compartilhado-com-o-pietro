parte do tutorial 3

<praticando/>

Você já conhece as tags principais. Agora vamos entender o que cada parte de um código faz, ver mais exemplos prontos e, no fim, praticar copiando um código para criar o seu próprio.

conceito 1

O que cada parte do código faz

Repare nos três pedaços de uma tag: o nome (diz o que ela é), os atributos (informações extras, como class="cartao") e o conteúdo (o que fica entre a abertura e o fechamento). É essa combinação que forma cada elemento da página.

exemplo.html
resultado
<!-- nome da tag: a --> <a href="#"> <!-- atributo: href --> Clique aqui <!-- conteúdo --> </a> <ul> <li>Item 1</li> <li>Item 2</li> </ul>
conceito 2

Mostrando mais exemplos

Quanto mais exemplos você vê, mais fácil fica reconhecer o padrão. Aqui está um exemplo um pouco maior, juntando várias tags que você já conhece dos tutoriais anteriores em uma única página.

pagina.html
resultado
<h1>Meu primeiro site</h1> <p>Bem-vindo à minha página!</p> <ul> <li>Sobre mim</li> <li>Projetos</li> </ul> <a href="#">Fale comigo</a>
conceito 3

Sua vez de praticar

Copie o código abaixo, cole em um arquivo .html no seu computador e mude os textos, os links e os itens da lista. Não tem como errar — é só testar e ver o resultado mudar.

exercicio.html — copie e edite
<h1>Coloque seu título aqui</h1> <p>Escreva uma frase sobre você</p> <ul> <li>primeiro item</li> <li>segundo item</li> </ul> <a href="#">seu link aqui</a>
Curiosidade: a indentação (os espaços no início das linhas) não muda nada para o navegador — ela existe só para ajudar você, humano, a ler o código mais fácil.
